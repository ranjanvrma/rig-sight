    Home/Architecture

    Architecture

    A LangGraph hub and spoke: every agent reads and writes one shared state and hands back to the Orchestrator.

    Orchestrator

    Plain Python route() reads the shared state and picks the next agent. No model, fully predictable.

    Planner and Research

    Plan the work for this report, then pull the well plan, budget, NPT codes and similar past incidents.

    Executor and ToolNode

    Six Python tools parse, classify, sum, and compute ROP, depth and cost. The model only labels lines.

    Critic

    Checks 24 h, gaps, overlaps, bad lines, categories and evidence. Sends fixable problems back, at most three times.

    Engineer

    interrupt() pauses the graph. Approve ends the run; reject with a comment re-runs it with your corrections.
